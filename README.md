# NEXUS Sidekick

Experimental non-root Android floating assistant alpha.

Supports movable overlay shortcut, Android voice input, opening YouTube/settings/camera/browser, and YouTube/Google search. Build the APK from Actions → Build NEXUS APK → Artifacts.

This is an alpha, not a fully autonomous AI agent. Gemini, Yantra, Anthropic and accessibility automation are not implemented yet. Never commit API keys.
